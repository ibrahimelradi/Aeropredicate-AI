🔄 2. Turnaround Optimization

Predictive task sequencing for aircraft ground operations.

POST /api/turnaround/plan
{"flight_number":"TK1988","dep_airport":"IST",
 "arr_airport":"JFK","airline":"TK",
 "date":"2026-10-20","dep_time":"14:30",
 "aircraft_type":"narrow_body","crew_count":5}
